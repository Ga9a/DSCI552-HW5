## Run

Use Python 3.12 and install the dependencies:

```sh
python -m pip install -r requirements.txt
```

Open the notebook in local Jupyter and run all cells from a fresh kernel.
Run from the repository root or `notebooks/`. All data paths are relative.
The notebook creates `results/` for generated tables and figures. The datasets
are included, so no downloads are needed. Cross-validation can take several minutes.

## Files

- `notebooks/`: executed notebook.
- `data/`: datasets and their descriptions.
- `requirements.txt`: Python dependencies.
